# Matplotlib Sales Analysis

## Project Overview
This project uses Python and Matplotlib to visualize retail sales and profit trends for Laptop and Mouse products across four months.

## Objectives
- Compare monthly sales across products.
- Visualize monthly profit trends.
- Practice Python data visualization.
- Generate charts for business reporting.

## Technologies Used
- Python
- Matplotlib

## Project Structure
```text
matplotlib-sales-analysis/
├── matplotlib_sales_project.py
├── README.md
├── requirements.txt
└── outputs/
    ├── monthly_sales.png
    └── monthly_profit.png
```

## Visualizations
- Monthly Sales by Product
- Monthly Profit by Product

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python matplotlib_sales_project.py`.

## Key Findings
- Laptop sales are higher than Mouse sales in every month.
- April has the highest sales and profit for both products.

## Note
This project uses illustrative sample data for learning and demonstration.
